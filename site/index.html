安装 ZenTao CLI

Node.js ≥ 18
$npm install -g zentao-cli

全局安装后，在任意目录使用 zentao 命令。

$bun install -g zentao-cli

已经在用 Bun？也可以用熟悉的方式安装。

$npx zentao-cli

适合临时体验 CLI。接入本页的 Agent 指南时，请选择 npm 或 Bun 全局安装。

再了解一点

需要什么运行环境？

通过 npm 安装或 npx 运行需要 Node.js 18 或更高版本，也可以使用 Bun。你还需要一个可访问的禅道服务器和具有相应权限的账号。独立可执行文件可从项目发布页查看。

支持哪些禅道版本？

ZenTao CLI 基于禅道 RESTful API v2，支持开源版、企业版、旗舰版和 IPD 版。不同操作有不同的最低版本要求，运行 zentao <模块> <操作> --help 查看具体要求。CLI 会在发送业务请求前检查版本兼容性。

Skill 和 MCP 怎么选？

支持执行终端命令的编码 Agent，可以安装 Skill，让它按技能说明使用 CLI。 需要通过标准工具协议接入时，选择 MCP。两种方式都需要先安装 CLI 并登录禅道， 按上方对应客户端的指南配置即可。

Agent 提示找不到 zentao 命令？

先在 Agent 所在电脑的终端运行 zentao --version，确认已全局安装。 桌面客户端可能未读取终端的 PATH，可在 MCP 配置中将 command 的 zentao 改为可执行文件的绝对路径，然后重启客户端或重连服务。

ZenTao CLI 是开源的吗？

是的。ZenTao CLI 使用 MIT 许可证，源代码公开在 GitHub。欢迎提交 Issue、改进文档或贡献代码。查看 GitHub 仓库。
