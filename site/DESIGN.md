# ZenTao CLI 网站设计

面向使用 AI Agent 的中文开发者，让访客先看到禅道如何进入 Agent 工作流，再选择客户端、完成接入并发起第一条查询。CLI 的功能与命令为这一使用方式提供依据。首页属于品牌宣传页，文档属于内容阅读页，命令检索页保留工具的紧凑布局；三者共享 Pixel Tao 的深海蓝、像素几何和克制的材质层次。

- **品牌**：使用 `public/brand/` 内的原始 Pixel Tao 资源，保留既有造型，不重绘 Logo。
- **字体**：Manrope 搭配系统中文字体用于正文和标题，JetBrains Mono 用于品牌字标、命令、代码、终端内容及能力统计；字体本地构建交付。中文保持自然字形，不使用像素字体影响阅读。
- **主题**：初次访问跟随本机系统主题，允许手动切换并保存选择；未手动选择时继续跟随系统变化。
- **样式来源**：`src/styles.css` 的语义 tokens 是颜色、字体和圆角的唯一来源。面板使用 4px、控件使用 3px、紧凑标签与步骤编号使用 2px 圆角，以方正轮廓呼应 LOGO 的像素构造。
- **首屏标识**：原始 LOGO 与等宽字标构成清晰的品牌组合，桌面 LOGO 为 96px、手机为 72px。仅在首屏使用低对比的 24px 网格，呼应像素构造；终端与标志保持正向对齐，不旋转、不作淡色水印。避免游戏化像素字体、霓虹色、漂浮光斑和无意义的装饰编号。
- **色彩与材质**：雾白 `#f3f6f7`、深海蓝 `#0b2a43`、强调蓝 `#174d70` 来自原始品牌资源；深色页面使用墨蓝 `#06111e` 和浅钢蓝 `#91b9cb`。终端固定使用深海蓝，细边线、顶边微光与短阴影表达材质，普通内容面板保持平整。
- **内容顺序**：首屏 Agent 场景 → Agent 选择与接入 → CLI 能力 → 安装登录 → FAQ。首屏用自然语言提问及对应的禅道查询说明用途，主行动入口引导到客户端选择。宣传数字与命令以项目实际能力为依据，终端、结构化输出和对话内容为明确标注的演示数据。
- **接入选择**：提供 12 个客户端，默认选择 Claude Code。桌面使用左侧客户端列表、右侧指南，移动端保持选择入口和当前指南清晰可见。名称旁的 Skill / MCP 标签说明当前优先方法，不使用装饰编号。
- **Agent 图标**：使用 lobe-icons 的对应单色 SVG，随站点主题继承颜色；选择项图标为 20px，当前指南标题图标为 30px。保留完整客户端名称，图标不重复提供辅助名称。资源保存在 `public/brand/agents/`，由指南渲染器在构建时内联，图标名称由 `src/agent-guides.ts` 统一维护。
- **方法层次**：Claude Code、Cursor、Codex、VS Code Copilot、OpenCode、Gemini CLI、Antigravity 优先展示 Skill 安装，MCP 放在可展开的备选方法中；Claude Desktop、Cherry Studio、Windsurf / Cascade、Cline、TRAE 直接展示 MCP。每份指南包含操作步骤、验证方法、可复制的示例提问和官方文档入口。
- **前置条件**：在选择区明确提示，先在 Agent 所在电脑全局安装 CLI、完成登录，并确认 `zentao product` 可正常查询。本地 MCP 复用本机登录，切换账号后需要重连，操作权限来自禅道账号。
- **指南来源**：`src/agent-guides.ts` 是唯一内容来源，`guide-renderer.ts` 在 Vite 开发及构建时生成静态 HTML。维护时同时核对 CLI 行为和各客户端官方文档，保留来源链接；不要在交互脚本中复制一份配置。
- **交互**：统一各组标签页的键盘行为，当前选择、可操作焦点和面板关联必须明确；复制结果提供可见反馈，JSON 配置和表单字段保留换行。保持移动导航、无 JavaScript 时的主要内容及链接可用，遵循减少动态效果的系统偏好。
- **验收**：检查全部客户端切换、MCP 展开、命令与提问复制，以及多行 JSON 复制后的可解析性；在桌面和移动尺寸、浅深主题下检查溢出、阅读顺序与操作目标，并用方向键和 Home/End 验证切换及焦点。构建通过用于确认站点可交付，客户端实际接入另按指南验证。

设计拨盘：`DESIGN_VARIANCE = 6`，`MOTION_INTENSITY = 4`，`VISUAL_DENSITY = 4`。保持适度变化、克制动效与舒展的信息密度。

## 文档阅读

文档区沿用网站品牌、字体和主题，桌面布局为分类导航、正文和页内目录三列，窄屏先收起目录，让正文获得完整阅读宽度。正文以项目 Markdown 为唯一来源，保留代码、表格、折叠示例和既有锚点。目录与正文链接均保持站内阅读，外部项目来源链接仍指向原站点。

全文搜索在使用时加载章节索引；结果包括所属文档、章节标题和文字摘要，支持键盘进入结果及 Escape 收起，并提供加载、无结果和加载失败反馈。长命令保持代码原文并在代码块内部滚动，宽参数表使用独立滚动区域。代码复制只复制示例文本，不执行命令。

原命令搜索页以独立站内工具页保留模块、操作类型和参数筛选，提供返回文档及首页的入口，并共享主题选择。文档在无 JavaScript 时仍可阅读和跳转，只有搜索、复制和主动主题切换需要脚本。

## 运行时映射

采用现有运行时 tokens 为主的维护方式：`src/styles.css` → 首页与文档共享样式 / 命令检索页适配 → 控件。此文件记录视觉意图和已接受的值，不另生成一份主题。改动颜色或几何时同步更新两处；浏览器主题栏从运行时 `--page` 读取，避免脚本再次维护调色板。

前置元数据的 `colors.primary` 对应运行时 `--accent`。命令检索页保留原阅读器的布局与交互；`src/explorer.css` 将旧变量 `--bg` / `--text` / `--line` / `--accent-bg` 映射到共享的 `--page` / `--ink` / `--border` / `--accent-soft`，不复制配色。开发直接加载共享样式，生产复用首页编译后的 CSS 链接。

| 语义 | 浅色 / 深色 | 运行时变量 | 主要使用处 |
| --- | --- | --- | --- |
| 页面 | `#f3f6f7` / `#06111e` | `--page` | 文档背景、导航、浏览器主题栏 |
| 正文 | `#0b2a43` / `#e0ebef` | `--ink` | 标题、正文、品牌字标 |
| 品牌强调 | `#174d70` / `#91b9cb` | `--accent` | 按钮、链接、焦点、选中状态 |
| 终端 | `#0b2a43` | `--terminal` | 首屏演示 |
| 面板 / 控件 / 标签 | `4px` / `3px` / `2px`，两主题相同 | `--radius` / `--radius-small` / `--radius-label` | 卡片、搜索、按钮、步骤编号 |
| 文字 / 命令 | 本地 Manrope / JetBrains Mono | `--sans` / `--mono` | 页面文字 / 字标与技术信息 |

滚动条全局继承 `--scroll-thumb`、`--scroll-hover` 和 `--scroll-active`，页面预留滚动条空间。浅深主题保持相同排版和交互层次；仅在系统允许时播放入场和控件过渡，强制对比模式停用首屏装饰网格。
