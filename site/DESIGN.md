# ZenTao CLI 网站设计

面向使用 AI Agent 的中文开发者，让访客先看到禅道如何进入 Agent 工作流，再选择客户端、完成接入并发起第一条查询。CLI 的功能与命令为这一使用方式提供依据。采用雾白底色、Terminal Deep Blue 终端区域与蓝色强调；深色主题沿用同一语义层次。

- **品牌**：使用 `public/brand/` 内的原始 Pixel Tao 资源，保留既有造型，不重绘 Logo。
- **字体**：Manrope 搭配系统中文字体用于正文和标题，JetBrains Mono 用于命令、代码与终端内容；字体本地构建交付。
- **主题**：初次访问跟随本机系统主题，允许手动切换并保存选择；未手动选择时继续跟随系统变化。
- **样式来源**：`src/styles.css` 的语义 tokens 是颜色、字体和圆角的唯一来源。面板使用 12px、控件使用 7px 圆角；紧凑标签使用较小圆角，步骤编号使用圆形。
- **内容顺序**：首屏 Agent 场景 → Agent 选择与接入 → CLI 能力 → 安装登录 → FAQ。首屏用自然语言提问及对应的禅道查询说明用途，主行动入口引导到客户端选择。宣传数字与命令以项目实际能力为依据，终端、结构化输出和对话内容为明确标注的演示数据。
- **接入选择**：提供 12 个客户端，默认选择 Claude Code。桌面使用左侧客户端列表、右侧指南，移动端保持选择入口和当前指南清晰可见。名称旁的 Skill / MCP 标签说明当前优先方法，不使用装饰编号。
- **方法层次**：Claude Code、Cursor、Codex、VS Code Copilot、OpenCode、Gemini CLI、Antigravity 优先展示 Skill 安装，MCP 放在可展开的备选方法中；Claude Desktop、Cherry Studio、Windsurf / Cascade、Cline、TRAE 直接展示 MCP。每份指南包含操作步骤、验证方法、可复制的示例提问和官方文档入口。
- **前置条件**：在选择区明确提示，先在 Agent 所在电脑全局安装 CLI、完成登录，并确认 `zentao product` 可正常查询。本地 MCP 复用本机登录，切换账号后需要重连，操作权限来自禅道账号。
- **指南来源**：`src/agent-guides.ts` 是唯一内容来源，`guide-renderer.ts` 在 Vite 开发及构建时生成静态 HTML。维护时同时核对 CLI 行为和各客户端官方文档，保留来源链接；不要在交互脚本中复制一份配置。
- **交互**：统一各组标签页的键盘行为，当前选择、可操作焦点和面板关联必须明确；复制结果提供可见反馈，JSON 配置和表单字段保留换行。保持移动导航、无 JavaScript 时的主要内容及链接可用，遵循减少动态效果的系统偏好。
- **验收**：检查全部客户端切换、MCP 展开、命令与提问复制，以及多行 JSON 复制后的可解析性；在桌面和移动尺寸、浅深主题下检查溢出、阅读顺序与操作目标，并用方向键和 Home/End 验证切换及焦点。构建通过用于确认站点可交付，客户端实际接入另按指南验证。

设计拨盘：`DESIGN_VARIANCE = 6`，`MOTION_INTENSITY = 4`，`VISUAL_DENSITY = 4`。保持适度变化、克制动效与舒展的信息密度。

## 文档阅读

文档区沿用网站品牌、字体和主题，桌面布局为分类导航、正文和页内目录三列，窄屏先收起目录，让正文获得完整阅读宽度。正文以项目 Markdown 为唯一来源，保留代码、表格、折叠示例和既有锚点。目录与正文链接均保持站内阅读，外部项目来源链接仍指向原站点。

全文搜索在使用时加载章节索引；结果包括所属文档、章节标题和文字摘要，支持键盘进入结果及 Escape 收起，并提供加载、无结果和加载失败反馈。长命令保持代码原文并在代码块内部滚动，宽参数表使用独立滚动区域。代码复制只复制示例文本，不执行命令。

原命令搜索页以独立站内工具页保留模块、操作类型和参数筛选，提供返回文档及首页的入口，并共享主题选择。文档在无 JavaScript 时仍可阅读和跳转，只有搜索、复制和主动主题切换需要脚本。
