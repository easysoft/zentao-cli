## 合并 main（2026-11-11）

保留 main 的 0.4.3 版本、品牌构建、结构化 SDK 错误映射、根级登录/Token/MCP 入口与拆分后的 MCP 指南；纳入显式动作契约、SDK 0.8.4 和 WorkBuddy 登录撤销修复。`mcp serve` 从父命令读取共享参数，避免丢失传输方式或只读限制。

合并后本地验证：534 项测试通过（49 文件、7473 次断言），TypeScript、命令参考检查、Node 18 和当前平台独立程序技能导出、品牌包及 WorkBuddy Node 22 本地 npm 包生命周期验证通过。未重新运行真实禅道写入验收，未验证 WorkBuddy 客户端按钮流程，未推送或发布。上方及 HTML 报告中的旧 ZIP 验收结论已由本次本地 npm 包验证取代；正式提交包仍须通过已发布 npm 包的能力校验。

启动成本抽测：同机 Node 18.20.3、同一套 SDK 0.8.4 依赖，交替运行 `-V`，预热后各 14 次；合并前 main 中位数 194.10 ms，合并后 219.27 ms（约 +25 ms），压缩入口由 187,495 B 变为 188,978 B。该结果仅用于记录命令树注册成本，不代表跨机器性能保证。
