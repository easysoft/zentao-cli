01 · 显式批量目标

使用 --ids；先校验全部 ID，再去重。禁止创建操作批量化，部分失败保留逐项结果并返回非零退出码。

86fa6a7

02 · Schema 类型与输入冲突

字符串 007 / true 保真；数字、布尔、重复数组按 schema 解析；未知字段与重复来源冲突在认证前失败。

0a3b77d · e4587e4

03 · 真实命令树

统一 resource action target；根级 CRUD、do、隐式 list/get 已移除。auth/profile/config/mcp/skill/completion/self 各司其职。

e4587e4 · 2d981b6

04 · 请求体与显式 stdin

按 requestBody 能力支持 JSON、@file 和 @-，涵盖 SQL、关键词与向量 POST 查询；没有 @- 就不读 stdin。

0a3b77d

05 · 分页与处理范围

page/page-size/all/max-items 分离；聚合后统一处理。缺少 pager、重复页、空页仍宣称有更多数据时明确失败。

f7851f8

06 · 稳定 JSON 与数据保真

统一 {ok,data,meta}；保留 HTML，显式转换。raw 拒绝批量、本地处理与内置命令，使用退出码 0/1/2/130。

ce5e1d9 · 0aa1106

07 · 终端展示

默认 table 精简列；Markdown/JSON 不截断；空列表显示 0 条。异构键、标量数组和字面量点号字段有回归覆盖。

ce5e1d9

08 · 身份选择与配置并发

--profile 优先于完整环境凭据，再到默认账号。保存与选择分离；歧义和部分环境报错；配置短事务防止更新丢失。

623bae6 · 0aa1106

09 · 交互、期限和取消

no-input/yes/quiet/color 独立。取消覆盖 stdin、认证、预取、上传和批量执行；data-deadline 避免与全局 deadline 冲突。

2d981b6 · 0aa1106

知识 POST 搜索标记只读，SQL 保守归入写组；HTTP 不发现本地上传。共享用户分页查找，单个取消不误伤并发认证。
