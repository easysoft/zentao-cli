# 禅道 MCP

使用当前连接器提供的 `zentao_*` MCP 工具。按需调用 `zentao_action_help` 查看动作参数、示例和版本要求；不要用 CLI 命令替代连接器调用。

- 首次使用先调用 `zentao_profile`，完成认证并确认当前账号和站点。列出工具成功只表示 MCP 已连接。
- 账号权限沿用禅道。只查询时不执行写入；用户授权写入后，按返回 ID 查询并核对保存结果。写入超时先查询结果，再决定是否重试。
- 列表默认只返回一页；根据返回的 `pager` 翻页，不把当前页当作完整结果。用 `pick` 缩小返回字段。
- 凭据只在 WorkBuddy 连接器表单中填写，不在对话中收集或输出密码、Token，也不读取本地凭据文件。切换账号或站点时修改连接器表单并重新连接。
- 地址和账号必填，密码与 Token 至少填写一项。两者同时填写时优先使用 Token；过期的 Token 不会回退密码。使用密码登录时应清空旧 Token。
- E1001/E1006：请用户补全连接器凭据并重新连接。E1003/E1004：请用户检查密码或更新 Token 后重新连接；密码模式重新连接后会再次换取 Token。不要引导用户执行 CLI 登录。
- E1002/E5001/E5002：检查禅道地址、网络或证书；E2006：检查账号权限；参数或版本错误先查询动作帮助。

可在工具顶层 `assistant` 标注来源，如 `AI <WorkBuddy>`；不要把此标记放进业务参数。用户要求关闭时传空字符串。
